# Power-up art for the signature-move cut-in

Drop one picture per star here, named after the player's id (the same id as in `src/data/moves.ts`), for example:

    dragonball-son-goku.webp
    jjk-satoru-gojo.jpg
    bleach-ichigo-kurosaki.png

Any of `.webp`, `.png`, `.jpg`, `.jpeg` or `.gif` works. Keep each one small (about 30-60 KB; WebP is best) because it is downloaded by the player's phone the first
time that star hits one of the biggest sixes. A star with no picture here simply shows his portrait in the cut-in. No other change is needed.
